# GitHub Pages Upload

Upload every file and folder in this directory to the root of your GitHub repository:

- index.html
- app.js
- styles.css
- sw.js
- manifest.webmanifest
- README.md
- .nojekyll
- assets/

Then enable GitHub Pages:

Settings -> Pages -> Deploy from a branch -> main -> /root

Your public URL will be:

https://YOUR-GITHUB-USERNAME.github.io/my-first-islamic-journey/

If you already see only README.md in GitHub, that means the app files have not been uploaded yet.
